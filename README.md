# Linux Foundation Certified System Administrator (LFCS) — KodeKloud

[Course page](https://learn.kodekloud.com/learn/courses/linux-foundation-certified-system-administrator-lfcs) · **Instructors:** Jeremy Morgan and Alexandru Andrei · **Status:** completed, **LFCS passed** (May 2026)

## About

The LFCS is a hands-on exam from the Linux Foundation: you solve real admin tasks on live Linux systems, in the terminal.

This KodeKloud course prepares for it with short videos and many hands-on labs in the browser.

## Exam domains

| Domain | Weight |
|---|---|
| Operations and Deployment | 25 % |
| Networking | 25 % |
| Storage | 20 % |
| Essential Commands | 20 % |
| Users and Groups | 10 % |

## Course content

| # | Section | Topics |
|---|---|---|
| 1 | Essential Commands | Log in to Linux systems, files and directories, search, text processing, archives, permissions |
| 2 | Operations Deployment | Boot process, services, task automation, processes and resources |
| 3 | Users and Groups | User and group accounts, resource limits, advanced authentication |
| 4 | Networking | Network configuration, network services, routing, packet filtering |
| 5 | Storage Management | Partitions, LVM, RAID, encrypted storage, advanced file permissions |
